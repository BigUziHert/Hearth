# Hearth 1.0.5

- Canceling the Windows administrator prompt during hosting setup now returns to Hosting with a clear cancellation message.
- A canceled first setup no longer leaves a new, unreachable **This PC** connection in the launcher.
- Existing host connections and owner credentials are preserved when setup is canceled, so you can retry without losing access.

Update through Settings → Updates → Check for updates, then Download update and Restart to update.
