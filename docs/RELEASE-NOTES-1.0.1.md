# Hearth 1.0.1

The launcher now uses a dark charcoal interface with a pack sidebar, a landscape hero for the selected pack, a prominent Play button, and adjacent Off / Voxy / Distant Horizons controls.

- Select a real joined pack in the sidebar to switch its launch and terrain controls.
- Use **Add Modpack** to join a friend's invite or start creating a pack.
- Use **Manage Modpacks** for publishing, invites, membership, and host connections.
- Open a selected pack's **⋯** menu for access information, its instance folder, the previous installed release, and owner tools.
- Use **Settings** for Prism setup and Microsoft sign-in, with **Check for Updates** available in the footer.

This release retains the existing host protocol, pack authorization, transactional synchronization, Prism instances, and encrypted local profiles. Install it over 1.0.0; player worlds and settings remain outside the application installation directory.

For GitHub distribution, publish stable tag `v1.0.1` with `Hearth-Setup-1.0.1-win-x64.exe` and its `SHA256SUMS.txt`. Existing 1.0.0 launchers can use their configured source to check, download, and restart into this version.
