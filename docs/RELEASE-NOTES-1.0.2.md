# Hearth 1.0.2

- Restored standard Windows title-bar controls and clearer navigation, including a direct Hosting page.
- The pack's main button now follows its state: Add modpack, Check approval, Set up Prism, Play, Request access, or Play installed when offline.
- Publishing opens the host's packs automatically. Mods and Members have separate tabs, version choices load automatically, and local test invites are clearly distinguished from public invites.
- Hosting separates connecting an existing server, running a host on this PC, and sharing outside the home.
- Official Hearth updates work without entering a repository. Existing custom sources are preserved in Advanced settings.
- Update downloads are verified, cached for retry, and matched to the release tag. Release notes appear before download.
- Added Windows release automation, encrypted-profile migration checks, and WPF navigation/state regression checks.

Your existing profiles, worlds, settings, instances, and hosted pack data are preserved. Microsoft account sign-in stays in Prism. Updating an enabled Windows host service requires administrator elevation.
