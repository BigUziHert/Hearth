# Hearth 1.0.3

- Simplified Settings: launcher updates use official Hearth releases without a custom-source control.
- Kept Check for updates in Settings and removed the duplicate footer action.
- Moved Choose existing Prism into Minecraft settings, and the data-folder and guide shortcuts into Help.
- Existing profiles keep their pack credentials, hosts, Prism path, terrain choices, and other preferences. Legacy custom update sources are ignored.

Update through Settings → Updates → Check for updates, then Download update and Restart to update.
