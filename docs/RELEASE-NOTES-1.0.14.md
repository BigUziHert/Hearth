# Hearth 1.0.14

- Search the mods already imported into a pack by filename or group.
- Paste JAR files copied in File Explorer with **Paste mods** or **Ctrl+V**. Copy selected mods to another pack or folder, and drop JARs anywhere on the Mods card.
- Imported JARs are saved as verified draft copies. Rebuilding or deleting an original no longer breaks an unpublished draft.
- Choose another instance folder or drive under **Settings → Instance location**. Hearth copies and verifies existing worlds, mods, settings, and personal files before switching, retaining the original folder as a backup.
- Clarified hosting actions: enable hosting when it is off; retry incomplete connection setup while it is running. Removed the duplicate disabled “Hosting enabled” button.

Existing packs, hosting credentials, Microsoft accounts in Prism, and startup preferences are preserved. Close Minecraft and Prism before moving instances. Pack changes still require **Review & publish** before players receive them.
